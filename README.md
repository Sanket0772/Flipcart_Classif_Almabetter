# Flipkart Customer Service Satisfaction Classification

## Overview
This project analyzes customer service interactions and develops machine learning models to predict Customer Satisfaction (CSAT) scores.

## Objectives
- Explore customer service and satisfaction data.
- Clean and preprocess structured and textual data.
- Perform exploratory data analysis and feature engineering.
- Train and evaluate classification models.
- Identify factors associated with customer satisfaction.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- NLP and TF-IDF
- Google Colab

## Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. Categorical encoding and text preprocessing
4. Model training and hyperparameter tuning
5. Evaluation using accuracy, precision, recall, and F1-score

## How to Run
1. Download or open the notebook in Google Colab.
2. Obtain the dataset from its authorized source.
3. Update the dataset path in the notebook.
4. Run the notebook cells in order.
